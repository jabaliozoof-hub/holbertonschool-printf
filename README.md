# Custom printf() Implementation

A custom implementation of the standard C `printf` function, developed collaboratively for Holberton School. This project involves recreating the core functionality of formatted output, handling variadic arguments, and understanding low-level I/O operations.

## Description
The `_printf` function writes output to standard output (stdout) under the control of a format string that specifies how subsequent arguments are converted for output.

## Supported Conversion Specifiers
For Task 0, we have implemented the following core specifiers:
* `%c`: Prints a single character.
* `%s`: Prints a string of characters.
* `%%`: Prints a literal percent sign.
* `%i` / `%d` : Prints an integer.
